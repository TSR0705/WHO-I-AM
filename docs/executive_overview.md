# Exposur: Executive Overview

## 1. Project Synopsis

**Exposur** is a state-of-the-art privacy diagnostics and location intelligence platform. It analyzes a user's network routing, device properties, and browser fingerprints to demonstrate exactly what metadata is leaked to third-party servers. 

Rather than relying exclusively on third-party APIs (which introduces privacy leaks, request latency, and subscription costs), Exposur runs a **hybrid intelligence pipeline**. By compiling and optimizing GeoIP databases, cloud provider subnets, and Tor exit nodes at build time, it performs zero-latency location and anonymization queries directly in memory, while utilizing a central database and custom UDP server for uniqueness ratios and DNS leak analysis.

---

## 2. The Core Problem

Modern web applications silently gather massive amounts of metadata. Even behind VPNs and proxy chains, users remain vulnerable to:
* **DNS Leaks**: Systems querying public DNS resolvers outside the VPN tunnel.
* **WebRTC Leaks**: Browsers exposing local LAN IP addresses (e.g., `192.168.x.x` or `fe80::`) during STUN connection candidate negotiation.
* **Canvas, WebGL, and Audio Fingerprinting**: Hash identifiers generated by measuring GPU-specific canvas drawings, driver rendering offsets, and audio oscillator frequencies. Note: these are distinct identifiers, but identical hardware/software setups may yield the same hash.
* **Platform Discrepancies**: Inconsistent OS and browser settings that expose bot protection vectors.

Exposur exposes these leak vectors through an interactive, glassmorphism-themed, real-time dashboard.

## 3. Key Technical Innovations

### Localized Location & Routing Intelligence
Instead of making external API calls to resolve ASN and GeoIP parameters (which can block deployment pipelines and leak customer IPs), Exposur implements:
* **Brotli-Compressed MMDB Tables**: MaxMind GeoLite2 City and ASN databases are pulled at build time, compressed via Brotli to fit within Vercel's 50MB function zip limits, and decompressed directly in-memory at startup.
* **Binary-Search Subnet Lookups**: Google Cloud, AWS, and Cloudflare subnets are compiled, merged, and resolved using a logarithmic binary search ($O(\log N)$) across IPv4 and IPv6 space.

### Dual-Database Resilience
The Express API automatically runs under a **hybrid database model**:
* **PostgreSQL + Redis**: Production standard (e.g., Supabase/Neon + Upstash) for persisting canvas/audio hashes and tracking visit counters.
* **Local Memory + JSON File Fallback**: If connection credentials are absent, the application gracefully downgrades to local file-based database tables (`visits.json`, `dnsCache`) without crashing.

### Integrated DNS Leak Server
An integrated UDP DNS server (running publicly) parses incoming query subdomains (e.g., `<token>.dns.Exposur.com`) to track which DNS resolver IP addresses are making requests. If the resolver's location matches the user's ISP country rather than the VPN node's country, a DNS leak is flagged. This requires public internet routing and cannot be run strictly "offline".
